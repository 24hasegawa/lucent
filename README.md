# LUCENT — Design & Creative Engineering Portfolio

> **「透明に、触れる。」**  
> 光、素材、動き。デジタル空間に確かな手触りと心地よい秩序をもたらす、クリエイティブエンジニア / フロントエンドデザイナーのためのポートフォリオサイトです。

AppleのWebサイトに見られる洗練された余白、明確な情報の階層、繊細なタイポグラフィ、そして物理法則に基づく滑らかなWebGLインタラクションを統合しています。

## 2. 3Dガラスキューブの操作感

- **待機時**: 空間に静かに浮遊し、微細な回転を繰り返します（読書の邪魔にならない控えめな動き）。
- **スクロール時**: スクロール速度に応じた慣性力で自然に傾き・上下に揺れます。スクロールが止まると、ばねと減衰の物理計算によって滑らかに収束します。
- **ホバー時**: カーソルが `grab` に変化し、表面のハイライトがわずかに澄んで操作可能であることを伝えます。
- **ドラッグ時**: つかんだ位置のオフセットを保持し、カメラに正対した仮想3D平面上をスムーズに追従。移動速度に応じた自然な傾き（チルト）と重みを感じられます。
- **手放した時**: 直前の速度に応じた慣性を残し、各セクションの基本位置へ柔らかく戻ります。
- **位置リセット**: ナビゲーションバーまたは操作セクションの「位置を戻す」ボタン、もしくはキーボードの <kbd>R</kbd> キーで即座に初期位置へ復元できます。

## 3. 使用技術スタック

- **Core**: React 18 / TypeScript / Vite 5
- **3D & WebGL**: Three.js / @react-three/fiber / @react-three/drei
- **Styling**: Tailwind CSS / Modern CSS (Backdrop Blur, Custom Scrollbar, Ambient Glow)
- **Icons**: Lucide React
- **Physics**: カスタム・スプリング・ダンピング物理シミュレーション (Delta Time対応)

## 4. 起動とビルド

```bash
# 依存関係のインストール
npm install

# 開発サーバー起動 (http://localhost:5173/)
npm run dev

# プロダクションビルド & プレビュー
npm run build
npm run preview
```
